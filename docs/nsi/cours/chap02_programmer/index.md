# Programmer
## Le pitch

Les langages d’assemblage, qui permettent de commander « directement » le fonctionnement du processeur et de la mémoire d’un ordinateur, sont appelés des **langages de bas niveau**. Ils sont composés d’instructions élémentaires très simples qui sont exécutées de manière séquentielle, l’une après l’autre, par l’ordinateur : on parle de **programmation impérative**. Cependant, ces langages sont difficiles à manipuler pour les humains.

Pour faciliter la programmation, les informaticiens ont conçu, à partir de ces langages de bas niveau, des langages dits **« de haut niveau »**. Ces langages fournissent des concepts qui facilitent la résolution de problèmes, sans avoir à se soucier de la façon dont l’ordinateur met en œuvre le programme.

Le langage **Python** fait partie des langages impératifs de haut niveau : il est aisément manipulable par les humains, tout en restant proche du principe de fonctionnement de l’architecture interne de l’ordinateur. Le langage Python est actuellement l’un des langages de programmation les plus utilisés dans le monde.
