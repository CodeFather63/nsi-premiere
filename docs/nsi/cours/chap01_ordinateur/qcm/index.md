## 5. Sachant que les emplacements mémoire X et Y contiennent des nombres positifs, quelle est la valeur de l’emplacement mémoire Z à la fin du programme ?

```asm
LOAD X
SUB Y
CMP Y
JMPZ a
LOAD #1
STORE Z
HALT
```

-  a. X − Y  
-  b. X − 2Y  
-  c. 1 si X = Y, 0 sinon  
-  d. 1 si X ≠ Y, 0 sinon  
-  e. 1 si X = 2Y, 0 sinon  
-  f. 1 si X ≠ 2Y, 0 sinon
