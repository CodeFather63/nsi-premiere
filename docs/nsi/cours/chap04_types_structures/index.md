# Le pitch

Les types de base introduits dans le chapitre 2 (booléens, nombres, chaînes) s'avèrent insuffisants pour traiter des problèmes où l'on a affaire à des collections de données, comme par exemple des mesures de température collectées à intervalles réguliers ou des données structurées telles qu'un annuaire, un catalogue de produits, un emploi du temps, etc.

Ce chapitre introduit les types structurés de Python (aussi appelés types construits ou collections) : les tuples, les tableaux, les listes et les dictionnaires. Ces types sont indispensables pour manipuler des données complexes car ils permettent de représenter des valeurs composées de plusieurs éléments alors que les types de base du chapitre 2 ne représentent que des valeurs simples.
